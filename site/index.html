sshexplorer is a desktop app that opens a remote filesystem over SSH and shows each file beside the listing: source, Markdown, images, PDFs, archives, logs as they grow. It uses the keys, agent and ~/.ssh/config you already have, and installs nothing on the host.

What is in it

NameWhat it does
Tree view The whole filesystem from / down, opened a directory at a time. A Session starts here.
Folder view One directory's entries, sortable by name, size, time or permissions. Breadcrumbs take you back up.
Preview The focused file, shown beside the listing. Text, highlighted source, rendered Markdown, images, PDF, archive listings, audio and video.
Follow Keeps a log file's latest lines on screen as the host writes them.
Search Finds files and directories by name. It runs on the host, from the directory you are in.
Download Copies what you selected, directories included, to a local folder. Four files at a time, with optional zstd for large text.
Readonly On for every new Host. Its Sessions cannot change the remote filesystem.
Reconnect A dropped connection keeps its tab and listings, and comes back by itself.

Build it

There are no packaged releases yet. sshexplorer is a Rust crate; audio and video Preview link against GStreamer, so install that first.

macOS

brew install gstreamer pkgconf
git clone https://github.com/mnj/sshexplorer
cd sshexplorer
cargo run --release

Debian and Ubuntu

sudo apt-get install pkg-config \
  libgstreamer1.0-dev \
  libgstreamer-plugins-base1.0-dev \
  gstreamer1.0-plugins-good gstreamer1.0-libav
git clone https://github.com/mnj/sshexplorer
cd sshexplorer
cargo run --release

Fedora, Arch and Windows are in the build notes.

What it does not do yet

  • Open a Session that needs ProxyJump or ProxyCommand.
  • Upload, rename or delete. Sessions browse and download.
  • Search inside files. Search matches names.
